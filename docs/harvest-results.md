# Расчёт результатов уборки

Плотность задаётся независимо для каждого HarvestDay: MIN, AVERAGE, MAX или CUSTOM.
Таблица HarvestDensityCatalog соответствует значениям технического задания, кг/м³.
Это ориентировочные значения, зависящие от влажности и состояния зерна.
Новый день всегда получает MIN по текущей культуре; для «Другое» — null.
Изменение культуры сохраняет плотности старых дней и требует явного подтверждения предупреждения.

Объём: FULL=1, HALF=0,5, MORE_THAN_HALF=0,5–1, LESS_THAN_HALF=0–0,5.
Масса=объём×плотность/1000; ц/га=масса×10/площадь; т/га=масса/площадь.
Границы сохраняются, все результаты обозначены приблизительными.
Кампания: сумма известных масс, сумма известных площадей. Урожайность только по
дням с одновременно известными массой и площадью; неполный расчёт явно обозначен.
Неизвестная масса не превращается в ноль.

Пустая площадь означает null. Площадь можно добавить, изменить или очистить после
завершения кампании. Числа должны быть положительными и конечными; запятая и точка поддерживаются.
Настройки событий и таймеров доступны через отдельный пункт меню шестерёнки.

Room 20→21: три nullable-колонки harvest_days, минимальные плотности по культуре
для старых дней. Старые значения всех таблиц не меняются. Резервные копии v18–20
проверяются до восстановления; недостающие новые поля заполняются безопасно.
Восстановление v21 и импорт сохраняют индивидуальные значения, включая CUSTOM.

## Хронология и повторное открытие

Все сохранения времени через HarvestDao проверяются транзакционно. Окончание
не раньше последнего бункера; бункер завершённого дня не позже окончания;
изменение начала сохраняет сторону полуночи существующих бункеров.
HH:mm раньше начала — следующие сутки, смена менее 24 часов. Схема не содержит
дат отдельных бункеров и не представляет смены длительностью 24 часа и более.
Существующие записи не исправляются автоматически; конфликтующее сохранение
отклоняется с указанием времени. Бункеры сортируются относительно начала смены.
Повторное открытие дня транзакционно открывает кампанию; второй активный день
запрещён. Кампания с активным днём показывает «Продолжить рабочий день», без
активного — «Новый день». Площадь и плотность при повторном завершении сохранены.

## Планируемая точная шкала — Issue #48 (ещё не внедрено в main)

Это утверждённые ТРЕБОВАНИЯ на будущее по Issue #48, а не факт реализации
в текущей основной ветке и не объявление о выпуске функции. PR #66 отдельно
реализует Android-часть. Приведённый выше текст об интервалах сохраняется
как история прежней модели.

Планируемая шкала заполнения: меньше половины = 25% (коэффициент 0.25),
половина = 50% (0.5), больше половины = 75% (0.75), полный = 100% (1).
Для комбайна используется одно числовое значение паспортного объёма бункера:
NOVA 340 — 4.7 м³. Объёмы суммируются без диапазонов.

Объём м³ = сумма(паспортный объём бункера м³ × коэффициент заполнения).
Масса т = сумма по дням(объём дня м³ × плотность дня кг/м³ / 1000).
При разных плотностях каждый день рассчитывается со своей плотностью,
после чего массы складываются. Итоговая масса — одно числовое значение,
без диапазона. Урожайность т/га = масса т / площадь га;
урожайность ц/га = урожайность т/га × 10. Итоговая урожайность в каждой
единице измерения — одно числовое значение, без диапазона.

Округление выполняется только при отображении, промежуточные значения
не округляются. Неизвестные значения не заменяются нулём; неполный расчёт
явно обозначается. Урожайность рассчитывается только по дням с одновременно
известными массой и площадью.

Пример будущего расчёта: 10 полных бункеров и один 25%-ный при паспортном
объёме 4.7 м³ и плотности 720 кг/м³:
объём = (10 × 1 + 1 × 0.25) × 4.7 = 48.175 м³;
масса = 48.175 × 720 / 1000 = 34.686 т.
