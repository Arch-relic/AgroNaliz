# АгроНализ — реестр будущих релизов

Дата фиксации: 11.10.2026. Статус: план, не реализация.

## Правила
- GitHub Issues — конкретные задачи; этот файл — обзор версий.
- Новые решения записывать в этот файл и/или Issues, а не полагаться только на историю чата.
- Версии и сроки не являются обязательством до отдельного согласования.
- Не объединять ветки и PR в main без явного разрешения владельца.

## v1.0 — текущий релиз
- Завершить действующие функции и тестирование.
- Существующая локальная библиотека PDF и поисковых индексов остаётся рабочей.
- Облачная синхронизация **не обязательна** для выпуска v1.0.

## v1.1 — запланировано
### Централизованная библиотека технических документов через Яндекс Диск
- Владелец публикует PDF и соответствующие поисковые индексы в облаке.
- Пользователи скачивают документы без входа в Яндекс и без платной подписки.
- Удалённый каталог с постоянными ID документов, версиями, размером и контрольными суммами.
- Проверка целостности, безопасное обновление и сохранение последней исправной локальной копии.
- Офлайн-просмотр и поиск после скачивания.
- Ручная проверка обновлений на первом этапе.
- Не встраивать в APK OAuth-токены или ключи владельца Яндекс Диска.
- Проверить условия и ограничения публичной раздачи файлов, а также реальную работу на Android.
- Архитектуру оставить расширяемой на другие облачные источники.
- Существующий Google Drive Draft PR #7 — экспериментальная работа, **не сливать** в main автоматически; решение о судьбе принять отдельно.

### Библиотека техники вне парка (предварительный пункт)
- Возможность доступа к документации техники из справочника, даже если техника не добавлена в парк. Исторически намечено на v1.3; перенос в v1.1 **не согласован**, поэтому пока оставить в v1.3.

## v1.2 — требуется восстановление подробного плана

- Остальные ранее обсуждённые функции требуют переноса из сохранённых планов после сверки.

## v1.3 — предварительный план

- Остальные ранее обсуждённые функции требуют переноса из сохранённых планов после сверки.
