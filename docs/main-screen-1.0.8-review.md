изменения5c1c74b9299f13537369da6180747140063f7ab5, main4d9ecfe7b7fb83a12f191d40855fdcd1c13cbaee.
Статус: изменение и тесты подготовлены, новый CI ещё не завершён.

## Изменения

Полностью перенесены в конец «Опций»: разделитель, «Для разработчика», динамическая
версия с прежней TEST-пометкой, «Справочник техники» и «Резервное копирование».
Обработчики открывают прежние DeveloperCatalogActivity и BackupRestoreActivity.
Прежняя кнопка «Данные и резервные копии» в Options продолжает открывать
DataBackupActivity. Ничего в реализации экспорта/восстановления не менялось.

Главный экран сохраняет кнопки техники/полей/рабочих записей/опций и условную
«ПРОДОЛЖИТЬ УБОРКУ». Gap перед «Опциями» не уменьшен: прежний Space56dp и margin16dp.
Продолжение уборки — последний элемент после Space с весом1; minHeight96dp,
wrap_content позволяет вырасти для крупного шрифта, ширина match_parent, текст
центрирован. Внизу24dp padding плюс системные inset через fitsSystemWindows.
При отсутствии активной кампании прежняя логика устанавливает GONE, отдельной
обёртки/зарезервированной высоты нет. Оба экрана ScrollView с fillViewport:
при нехватке высоты свободный Space сжимается, контент прокручивается.

Бизнес-логика refreshHarvest/openHarvest/quickAccessGeneration/DAO не изменена.
Room23, миграции, резервное копирование, applicationId/подписи, версии и workflows
не изменялись. Опубликованная ранее TEST APK не пересобирается/не публикуется этой
задачей, новые APK на пользовательские устройства не устанавливаются.

- AppVersionUiTest перенесён на OptionsActivity: версия, центрирование/размер,
  доступность обеих перенесённых кнопок; существующие три запуска MAIN/TEST/TEST

- Новый MainScreenLayoutUiTest: навигация из Main в Options и по всем трём кнопкам

  Все прежние QuickAccess, уборка/backup/миграции/подпись TEST остаются обязательными.

внешние глубокие ссылки/существующие Activity не менялись. Изменена только UI-
